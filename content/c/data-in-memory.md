## 1.整数在内存中的存储

整数的2进制在计算机中表示有三种方式，即原码，反码，补码

有符号的整数三种表示方法均有符号位和数值位，符号位用0表示正，1表示负，最高位的一位即被当成符号位，其余位是数值位

正整数的原码 反码 补码相同   

负整数的三种表示方法各不相同

原码：负整数的原码将数值按照正负数的形式翻译成2进制得到的就是原码，最高位是符号位

反码：原码符号位不变（最高位不变）其余位按位取反（0变1,1变0）可以得到反码

补码：反码+1就可以得到补码

这是因为计算机中只存在加法，因此用补码来表示和存储才可以正常运算

因此数据存储是一个循环，以char类型为例

## 2.大小端字节序和字节序的判断

大端存储模式：指数据低位字节内容保存在内存的高地址处，而数据的高位字节内容保存在低地址处

小端存储模式：指数据高位字节内容保存在内存的高地址处，而数据的低位字节内容保存在低地址处

下面看一个代码

```c
#include <stdio.h>
```


```c
int main()
{
    int a = 0x11223344;
```


```c
    return 0;
}
```


下面的图是a的内存存储方式

![](/images/c/824405b9414d42488101d8403cb2d939.png)

44其实是a的低位字节内容，也保存在了内存的低地址处，所以VS2022里面是小端存储模式

### 写一个代码判断是大端还是小端

```c
#include <stdio.h>
```


```c
int main()
{
    int a = 1;
    char* p = (char*)&a;//大端模式a的内存是 00 00 00 01
                        //小端模式a的内存是 01 00 00 00
                        //取出了a的第一个字节来判断
    if (*p == 1)
    {
        printf("小端\n");
    }
    else
    {
        printf("大端\n");
    }
    return 0;
}
```

## 3.浮点数在内存中的存储

浮点数类型有float double long double

浮点数在计算机内部表示方法如下

![](/images/c/91c3a107dba048eaad895259b20ba352.jpeg)

十进制的5.0写成二进制是101.0，相当于1.01\*2^2

即S=1，M=1.01，E=2，所以浮点数在计算机中不能精确保存

对于32位的浮点数，最高的1位存储符合位S，接着的8位存储指数E，剩下的23位存储有效数字M

对于64位的浮点数，最高的1位存储符号位S，接着的11位存储指数E，剩下的52位存储有效数字M

![](/images/c/ec87a340512c4cc9a07939d5376bee1b.png)

并且计算机内部保存M时，默认这个数的第一位是1，也就是M可以写成1.xxxxxxxx的形式，xxxxxxxx是小数部分，因此这个数的1可以舍弃，只保存后面xxxxxxxx部分，等到读取的时候再加上1，这样可以节省1位有效数字。相当于32位下M可以保存24位有效数字

对于指数E，E是一个无符号整数，意味着E如果是8位，它的取值范围是0~255；E如果是11位，它的取值范围是0~2047.但是我们知道科学计数法E是可以出现负数的，所以规定存入内存时E的真实值必须加上一个中间数（8位的E是127,11位的E是1023）

E还有三种情况

（1）E不全为0或1（正常形式）

指数E- 127就可以得到真实值

（2）E全为0（有效数字M的隐含1规则失效，M直接表示为0.xxxxxxxx）

这是浮点数的指数E等于1-127（或1-1023），这时2^E次方很小，是一个接近0的数（但不是0），所以也不需要特殊处理

（3）E全为1

M全为0，表示无穷大符合取决于S

M不全为0，表示非数NaN，无效运算结果
