## if语句在分支中具有着重要的作用

形式如下

```c
if（表达式）

语句
```


如果有多个语句，要记得使用{}，否则只执行第一条语句，同时表达式中0为假，非0为真，意思就是非0才会执行语句

### 使用if语句就可以和else语句搭配使用了

如果if表达式为假，我们可以使用else语句形式如下

```c
if（表达式）

语句1

else

语句2
```


意思就是如果如果if表达式为假，可以输出else语句，同样如果要使用多个语句，记得用{}，else和if也可以连用，使得不同情况都有不同输出

```c
if（表达式）

语句1

else if （表达式）

语句2

……………

else

语句…
```


还有记住else语句总是和最近的if匹配，否则会进入嵌套

例如if（表达式）

if（表达式）       语句

else          语句

其实真实情况是if（表达式）

{if（表达式）        语句

else                 语句}

## 关系操作符 条件操作符 逻辑操作符

>大于       <小于       >=大于等于      <=小于等于

==相等（=是赋值）     ！=不相等

同时多个关系运算符不适合连用，因为计算机是从左到右计算

如i<j<k 先判断i<j
为真则为1，假则为0，然后才会和k进行比较，不能产生我们想要的效果，这时我们就可以用逻辑操作符

！逻辑取反运算符（改变单个表达式的真假）

&& 逻辑与运算符，并且的意思

||    逻辑或运算符，或者的意思

用来表达上面的i<j<k就可以写成i<j&&j<k

条件操作符也叫三目操作符，形式

```c
exp1 ？exp2 ：exp3
```


意思是exp1为真，exp2计算，exp1为假，exp3计算

## switch语句

这可以用来优化多个的else if 语句

```c
switch（expression）{

case value1：statement

case value2：statement

default：statement

}
```


switch后的expression和case后的值必须为整形表达式，同时case语句后加break才可以结束

case语句和default语句也并不要求顺序，只不过一般把default放在最后

break和continue语句

break 的作⽤是⽤于永久的终⽌循环，只要 break
被执⾏，直接就会跳出循环，继续往后执  
⾏。  
continue 的作⽤是跳过本次循环中 continue 后边的代码，在 for 循环和 while
循环中有  
所差异的。

```c
int i =1；

while（i<=10）

{

if（i==5）

continue；

printf（“%d”，i）；

i++；

}
```


```c
for（int i=1；i<=10；i++）

{

if（i==5）

continue；

printf（“%d”，i）；

}
```


while循环中只输出1 2 3 4  而for循环可以输出1 2 3 4 6 7 8 9 10

do while循环和while循环中情况类似，就不在列举了

## goto语句

goto语句可以实现在同一个函数内跳转到设置好的标号处

但为了防止乱跳，我们一般避免使用goto语句，当然如果想要快速跳出多循环，goto语句就很有用了
